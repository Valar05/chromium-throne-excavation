## Recovered identity

Chromium Throne was not a standalone repository and not merely a browser plugin. It was a subsystem inside `Valar05/home-center`, primarily under `browser-porch/`.

The subsystem combined:

- a Manifest V3 Chromium extension;
- side-panel UI;
- a background service worker;
- visible authenticated ChatGPT tabs;
- content-script/browser-tab control;
- persistent tab/worker identity;
- a local Node relay and CLI client;
- a dedicated browser profile;
- scheduled-task/watchdog persistence;
- later phone/Termux/SSH integration attempts.

The earliest recovered source name is **Browser Porch**. **Chromium Throne** became the product/system name.
